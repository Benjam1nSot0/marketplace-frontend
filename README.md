
Aplicación web cliente desarrollada con React y Vite para la gestión y exploración de publicaciones en un mercado digital interactivo. Proyecto desarrollado para la certificación Full Stack Javascript de Desafío Latam.

* **Aplicación en Producción (Netlify):** [https://marketplacedesafiolatam.netlify.ap]

---

# Tecnologías Utilizadas
* **React 18** + **Vite**
* **React Router DOM v6** (Navegación y Rutas Protegidas)
* **Context API** (`UserContext`, `PostsContext`)
* **Bootstrap 5** (Estilos y diseño adaptativo)
* **HTML5 / CSS3 / JavaScript ES6+**

---

## Requisitos Previos
* Node.js (v18 o superior)
* npm o yarn
